# 🎬 YouTube Downloader Telegram Bot

Стильный, минималистичный Telegram-бот для скачивания видео и плейлистов с YouTube с возможностью выбора качества (от 480p до 1440p). Бот разработан с использованием современного асинхронного фреймворка **aiogram 3.x** и утилиты **yt-dlp**.

## ✨ Основные возможности

*   **⚡ Умный анализ ссылок**: бот автоматически распознает ссылки на обычные видео, Shorts, Live-трансляции и плейлисты.
*   **🎭 Разрешение на выбор**: поддержка разрешений `480p`, `720p (HD)`, `1080p (FHD)` и `1440p (2K)`.
*   **📁 Поддержка плейлистов**: возможность скачать весь плейлист (до 15 видео за раз) с отправкой каждого ролика по отдельности.
*   **🔀 Двойной выбор**: если ссылка содержит и видео, и плейлист (например, ссылка на видео внутри списка воспроизведения), бот предложит выбрать, что именно вы хотите скачать.
*   **🖼️ Красивое оформление**: видео отправляются с оригинальным названием, длительностью, разрешением и обложкой (thumbnail).
*   **🛡️ Контроль лимитов Telegram**: бот проверяет размер файла перед отправкой (лимит для стандартных ботов — 50 МБ) и предупреждает пользователя, если файл превышает лимит.
*   **🧹 Автоматическая очистка**: временные файлы видео и обложек удаляются сразу после отправки (или в случае ошибок), а при запуске и остановке бота проводится полная очистка папки загрузок.

## 🛠️ Технологический стек

*   **Python 3.10+**
*   **aiogram 3.x** (Асинхронная библиотека для Telegram Bot API)
*   **yt-dlp** (Форк youtube-dl для скачивания медиа)
*   **FFmpeg** (Необходим для слияния аудио и видео высокого качества)
*   **python-dotenv** (Управление конфигурацией через `.env`)

## ⚙️ Требования

Для работы бота на сервере или локальном компьютере должен быть установлен **FFmpeg**.

### Установка FFmpeg:
*   **Ubuntu/Debian**:
    ```bash
    sudo apt update && sudo apt install ffmpeg -y
    ```
*   **macOS** (через Homebrew):
    ```bash
    brew install ffmpeg
    ```
*   **Windows**: Скачайте сборку с официального сайта FFmpeg и добавьте путь к бинарным файлам в переменную окружения `PATH`.

## 🚀 Установка и запуск

1.  **Клонируйте репозиторий или перейдите в папку проекта**:
    ```bash
    cd yt-bot
    ```

2.  **Создайте виртуальное окружение и активируйте его**:
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    # venv\Scripts\activate   # Для Windows
    ```

3.  **Установите зависимости**:
    ```bash
    pip install --upgrade pip
    pip install -r requirements.txt
    ```

4.  **Настройте переменные окружения**:
    Создайте файл `.env` на основе примера `.env.example`:
    ```bash
    cp .env.example .env
    ```
    Откройте `.env` и впишите ваш токен бота, полученный от [@BotFather](https://t.me/BotFather):
    ```env
    BOT_TOKEN=1234567890:ABCDefGhIJKlmNoPQRsTUVwXyZ
    DOWNLOAD_DIR=./downloads
    ```

5.  **Запустите бота**:
    ```bash
    python3 bot.py
    ```

## 📝 Важная информация по качеству видео
YouTube хранит видео высокого качества (480p и выше) с разделенными потоками видео и аудио. Бот автоматически скачивает лучший видеопоток выбранного разрешения и лучший аудиопоток, после чего склеивает их в один контейнер `mp4` с помощью утилиты `FFmpeg` перед отправкой пользователю.
